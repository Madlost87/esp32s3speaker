# Example Model

Questa cartella contiene una copia di esempio del modello ESPHome microWakeWord `hey_jarvis` gia' scaricato/usato dal firmware.

File:

- `hey_jarvis.json`: manifest modello microWakeWord v2.
- `hey_jarvis.tflite`: modello TensorFlow Lite Micro.

Serve solo come riferimento di formato per produrre una wake word custom compatibile.
